# Code of Conduct

This project adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

We expect contributors to be respectful in all project spaces: GitHub issues, pull requests, discussions, and any other channels where contributors interact about this project.

## Reporting

Reports of unacceptable behavior may be sent privately via GitHub's private vulnerability reporting, on this repository's Security tab (the same channel used for security issues; the maintainers will route appropriately).
Direct link: [Security tab](https://github.com/Obviously-Not/concept-scanner-public/security).

The full Contributor Covenant 2.1 text governs enforcement decisions and is incorporated here by reference. See [contributor-covenant.org/version/2/1/code_of_conduct/](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
